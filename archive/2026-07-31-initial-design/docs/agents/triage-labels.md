# Triage Labels

工程技能使用五种标准分类角色。下表定义角色与本项目本地 tracker 状态字符串之间的映射。

| 工程技能角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不安排处理 |

当技能提到某种分类角色时，使用上表对应的本项目标签。若项目后续更改标签词汇，只修改本表右侧映射。
