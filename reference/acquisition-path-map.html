当前采集路径速查图

判断原则：先看谁拥有数据，再看谁只持有不可变快照。以下描述的是当前主线已接通行为。

端到端路径

配置
makeFactoryPreset()：10 MHz–26.5 GHz、201 点、二端口、source 1/2、IFBW 10 kHz、-10 dBm、100 ms。
源
makeSimulationSource() → simulateOpenPorts()：按 source/point/response 生成确定性复数接收机数据。
采集
ContinuousAcquisition::run()：source → 验证 → 附加 frame/sweep/sequence → 覆盖 raw latest。
等待
ContinuousTracePublisher::run()：waitForNext(afterSequence)，允许跳帧，不允许倒退。
测量
synthesizeSParameter()：当前 preset 固定 S21，计算 b[2] / a[1]。
投影
projectLogMagnitude()：复数 S21 → 20·log10(|S21|) dB。
存储
TraceDisplayFrameRepository::publish()：校验身份、格式、点数、有限值和 sequence，只保留最新帧。
查询
TraceDisplayFrameQuery：用当前 CommandBus 快照复核 Trace/Measurement/Format 绑定。
传输
DisplayFrameStream：等待新帧、编码 JSON、通过 WebSocket 推送；每连接单独维护 lastSent。
前端
LiveDisplaySession 解码并拒绝旧 sequence；App.vue 按 traceId 替换；CartesianCurve 生成 SVG path。

三个不要混淆的身份

sequence
原始采集先后顺序；跨消费和传输判断“更新”。
stateRevision
应用控制状态版本；当前固定发布器仍使用启动时 preset 的 revision 0。
generation
发布配置代次；目录与 frame set 已落地，动态发布器尚未接入当前运行链。

当前与下一步的边界

当前能跑：二端口 raw → 固定 S21/LogMagnitude → 单 Trace → 单帧 JSON WebSocket。

主线已具备基础：TracePublicationCatalog、generation、原子 TraceDisplayFrameSet、多格式前端解码器。

尚未接通：当前 publisher 捕获动态 plan、批量合成全部 Measurement、原子发布多 Trace frame set，以及 WebSocket/页面消费 frame set。
