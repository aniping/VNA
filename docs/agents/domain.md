# Domain Docs

本文件规定工程技能探索代码库时如何使用项目领域文档。

## 探索前读取

- 读取仓库根目录的 `CONTEXT.md`。
- 若将来存在根 `CONTEXT-MAP.md`，则按其中索引读取与任务相关的上下文文档。
- 读取 `docs/adr/` 中与当前工作相关的 ADR。
- 若某个文件不存在则静默继续，不为补齐形式而提前创建领域文档。

## 文件结构

当前仓库采用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── vna/source/
```

## 使用领域词汇

Issue 标题、规格、重构建议、测试名称和实现说明必须使用 `CONTEXT.md` 定义的正式术语，不得漂移为其中明确排除的同义词。

若需要的概念不在词汇表中，应先判断是否正在引入项目不存在的语言；确属领域缺口时，再交由领域建模流程补充。

## 标明 ADR 冲突

任何输出若与现有 ADR 冲突，必须显式指出所冲突的 ADR 和重新讨论理由，禁止静默覆盖既有决定。
