# 仿真后端输出原始接收机帧

正式 Simulation Backend 只输出与真实 Hardware Backend 相同语义的 RawReceiverPayload，而不是直接生成 S 参数或最终显示曲线。Application 协调器提供 FrameContext 与 FrequencyAxis，并将它们和 payload 组装成 RawReceiverFrame。虽然这使仿真实现更复杂，但能让测量合成、校准、去嵌、格式转换、Marker、文件导出和错误处理共享同一条数据链，并使无硬件测试能够验证真实系统的大部分行为。

默认仿真物理状态为所有测试端口开路、未连接 DUT。被激励端口的反射应接近理想开路，经过测量合成后 `Sii` 幅度接近 0 dB；未激励端口只接收到有限隔离泄漏和接收机噪声，`Sij` 落在随扫频轻微波动的噪声底。模型可以包含真实开路端口的寄生、电长度和小幅系统纹波，但不得虚构与开路场景无关的滤波器或谐振 DUT。

噪声在原始接收机样本层生成，而不是在最终 dB 曲线上事后叠加。它随帧、频点和接收通道变化，并受 IF 带宽与源功率影响；同一固定种子和帧序号必须可复现，以同时满足真实显示和确定性测试。Simulation Backend 必须按激励端口输出完整参考与响应接收机数据，使二端口或多端口 S 参数继续共享同一条测量链。
