# 采用单一同步文本运行日志

状态：已接受（2026-08-02）

## 决策

便携服务使用 spdlog 的同步、线程安全 sink 输出一套中文人类可读日志：

- 活动文件固定为发布根下的 `logs/vna.log`，单文件最大 10 MiB；
- 保留活动文件和四个归档，归档名为 `vna.1.log` 至 `vna.4.log`；
- 控制台镜像同一文本，Windows 控制台由宽字符输出支持中文；
- INFO 及以上级别每条刷新，正常返回路径再显式刷新一次。

日志初始化失败时，服务通过 stderr 和控制台提示后继续运行。运行中日志故障
也不改变 HTTP、采集或显示结果。强制终止进程仍不保证完成用户态刷新。

## 范围

本决策不恢复结构化事件、JSONL、公共 Logger 接口、异步队列、失败状态机或
旧日志迁移。除服务启动、工厂预置、连续采集和 Web 监听状态外，只记录成功
解码并完成派发的写命令业务结果；不记录请求体、测量数组、连续帧、读请求、
静态资源或 WebSocket 流量。

spdlog 类型只允许出现在少量私有 `.cpp` 和 PRIVATE 构建依赖中，不得进入领域
或公开头文件；需要新增调用点时，必须先证明它不是采集热路径。
