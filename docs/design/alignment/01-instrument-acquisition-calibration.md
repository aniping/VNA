# VNA 逐项对齐矩阵（第 1 分册）：仪器、采集与校准

本文把商用 VNA 的外部行为基线与当前架构建议逐项对齐，范围覆盖 Instrument、Channel、Stimulus、Sweep、Trigger、Average、Measurement、接收机波量、完整逻辑 Sweep、资源仲裁、Operation 和 Calibration。它不是实现清单，也不把架构建议自动视为产品决策。

状态使用以下七种值：

- `已明确`：用户已经明确表达的事实或约束；
- `已由证据定案`：相关外部事实已按 E1/E2 边界记录（如有），项目原生语义、E3 架构与验收路径已经闭合；不代表跨厂商共性或厂商内部实现相同，也不再要求用户凭感觉确认；
- `待产品确认`：确实需要决定是否交付、产品等级或部署/交互策略；
- `待兼容目标`：厂商确有不同，必须在选定主方言或产品 Profile 后冻结；
- `待算法/计量验证`：外部行为已定，但数值算法、边界和精度必须通过黄金数据与计量对照；
- `待底软/硬件确认`：取决于单板、底软、接收机拓扑或射频能力；
- `待平台验证`：设计方向已提出，但必须在目标 SDK/RTOS 运行环境中验证。

## 尚未闭合的责任门禁

1. **底软/硬件（24 项中的本分册部分）**：端口/source/receiver/route 拓扑，频率/功率/IFBW/点数/Segment 容量与量化，`a/b` wave definition、Z0、factory correction、quality、chunk ownership、trigger consumption、cancel/abort、forward/reverse 轴与 auxiliary observations。候选责任产物已经形成 [Board Adapter Interface 与合同测试契约](../board-adapter-contract.md)；真实 `CapabilitySnapshot`、底软签字、HIL 与故障注入记录仍未关闭。
2. **算法/计量（本分册 2 项）**：Response/SOL/one-path/full 2-port solver、病态矩阵与残余误差。责任产物是合成 error-box 黄金集、可溯源校准件、商用 VNA 对照和明确容差；仅有菜单或 SCPI 命令不算通过。校准步骤/质量报告的对象闭环已定案，具体阈值继续由该门禁和硬件证据约束。
3. **兼容目标（本分册 4 项）**：Segmented Sweep 扩展边界、Average input stage/sample boundary/count/clear 语义，以及 Correction interpolation/extrapolation、changed/degraded/rejected 的具体边界绑定到选定的 Keysight/R&S/CMT Compatibility Profile。项目原生默认使用单调不重叠 Segment、`MeasuredRatio + LogicalSweep` 且不静默外推。
4. **平台（本分册 2 项）**：chunk/queue/BufferPool 背压，以及不可中断底软调用的 worker 隔离、watchdog、恢复时间和资源回收，必须在公司 SDK/目标机长稳中关闭。
5. **已经收敛而不再询问用户的语义**：CW point、CW-Time 与 VNA Time Domain 分型；External Trigger 由模型支持并由硬件 capability 开放；Power Sweep 同样 capability-gated；配置只在完整轮次边界切换；缺少必需 sub-sweep 时不发布部分矩阵。
